# Nova AI 🌀 — إضافة PenguinMod

Nova AI إضافة مخصصة لمنصة PenguinMod تضيف بلوكات عربية للتواصل مع الذكاء الاصطناعي وإنشاء الصور.

## الملفات

- `nova-ai.js`: ملف الإضافة الذي يُحمّل في PenguinMod.
- `server.js`: خادم API الوسيط.
- `package.json`: اعتماديات الخادم وأوامر تشغيله.
- `.env.example`: نموذج إعدادات سريّة؛ انسخه إلى `.env` على الخادم ولا ترفع ملف `.env` إلى GitHub.

## تشغيل الخادم محلياً

يتطلب Node.js 20 أو أحدث.

1. نزّل المستودع إلى جهازك.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى ملف باسم `.env`.
5. ضع مفتاح OpenAI API في `OPENAI_API_KEY` داخل ملف `.env` على جهاز الخادم فقط.
6. نفّذ `npm start`.
7. اختبر `http://localhost:3000/health`؛ يجب أن يعيد JSON فيه `"ok": true`.

## نقاط API

- `GET /health`: اختبار أن الخادم يعمل.
- `POST /chat`: يستقبل `{ "prompt": "سؤالك" }` ويعيد `{ "text": "الإجابة" }`.
- `POST /images`: يستقبل `{ "prompt": "وصف الصورة" }` ويعيد رابط صورة محفوظة على الخادم.

## ربط PenguinMod

بعد نشر الخادم على عنوان HTTPS عام، ضع العنوان في بلوك «اضبط عنوان خادم Nova AI». ثم استخدم بلوك المحادثة أو إنشاء الصور.

يجب أن تسمح قيمة `ALLOWED_ORIGINS` بأصل الصفحة التي تشغّل الإضافة. لا تستخدم `*` في خدمة عامة إلا إذا فهمت مخاطر السماح لكل المواقع.

## الأمان والتكلفة

- لا تضع مفتاح API في `nova-ai.js` أو داخل مشروع PenguinMod أو في GitHub.
- ضع المفتاح في متغير بيئة سري لدى مزود الاستضافة.
- واجهات OpenAI API قد تتطلب فوترة منفصلة عن اشتراك ChatGPT.
- يوجد حد أولي للطلبات: 20 طلباً في الدقيقة لكل عنوان IP. هذا ليس بديلاً عن مصادقة المستخدمين أو نظام حصص إنتاجي.
- الصور المولدة تحفظ محلياً في مجلد `generated`. بعض منصات الاستضافة المؤقتة لا تحتفظ بالملفات بعد إعادة التشغيل؛ استخدم تخزيناً دائماً عند النشر الإنتاجي.

## ملاحظة

هذا خادم بداية قابل للتشغيل بعد إضافة مفتاح API صالح وتثبيت الاعتماديات. لم يتم نشره على الإنترنت بعد.
